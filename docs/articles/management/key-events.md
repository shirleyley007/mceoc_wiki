# Key Events

Key Events are customer-submitted events that require **dedicated support**. MCEOC displays them in the Team View to help engineers stay aware of important upcoming activities.

## Display Location

Key Events are shown in the Team View interface, positioned **above the engineer calendar**. Each event is represented as a **blue square block** on its corresponding dates. Dates affected by a Key Event will have highlighted borders on engineer's schedules as a visual reminder.

You can toggle the display of Key Events using the **Events** checkbox in the filter bar at the top of the Team View. When checked, events will be visible above the calendar; when unchecked, they are hidden.

![Key Events display](/key-events-overview.png)

## Event Details

Click on a blue square block to view the full details of the event. The detail panel may include Start/End date and time of the event, event contents, related ticket number, related Azure services, impacted pod etc. 

![Key Event details panel](/key-events-detail.png)

## Manage Key Events (TA/TM)

TAs and TMs can manually add, edit, and delete Key Events through the **Resource Center**.

### Access the Management Page

Navigate to **Resource Center** → **Events** from the left sidebar.

![Resource Center - Events](/key-events-resource-center.png)

### Filter and View Events

On the Key Events Management page:

- Use the **Year** dropdown and **Pods** checkboxes at the top to filter events
- The filtered results are displayed in a table below

For each listed event, you can:
- View basic info (Event Name, Start, End, Pods, Details)
- Click **Show details** to expand and view additional information
- Under **Actions**, click the edit (pencil) icon to modify or the delete (trash) icon to remove the event

![Key Events Management](/key-events-management.png)

### Add a New Event

1. Click the **+ Add Event** button
2. Fill in the required fields:
   - **Event Name** (required)
   - **Start** and **End** date/time (required)
   - **Pods (visibility)** — select which pods are affected (required)
3. Optionally fill in the **Details** section — you can add, edit, or remove detail rows (e.g., Details, Premier Case ID, Key Services, Contact Engineer Name)
4. Click **Save** at the bottom

After saving, refresh the Team View to see the newly added event.

![Add Event dialog](/key-events-add.png)
