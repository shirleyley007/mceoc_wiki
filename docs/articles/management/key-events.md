# Key Events

Key Events are customer-submitted events that require **dedicated support**. MCEOC displays them in the Team View to help engineers stay aware of important upcoming activities.

## Display Location

Key Events are shown in the Team View interface, positioned **above the engineer calendar**. Each event is represented as a **blue square block** on its corresponding dates. Dates affected by a Key Event will have highlighted borders on engineer's schedules as a visual reminder.

You can toggle the display of Key Events using the **Events** checkbox in the filter bar at the top of the Team View. When checked, events will be visible above the calendar; when unchecked, they are hidden.

![Key Events display](/key-events-overview.png)

## Event Details

Click on a blue square block to view the full details of the event. The detail panel may include Start/End date and time of the event, event contents, related ticket number, related Azure services, impacted pod etc.
