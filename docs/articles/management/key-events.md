# Key Events

Key Events are customer-submitted events that require **dedicated support**. MCEOC displays them in the Team View to help engineers stay aware of important upcoming activities.

## Display Location

Key Events are shown in the Team View interface, positioned **above the engineer calendar**. Each event is represented as a **blue square block** on its corresponding dates.

![Key Events display](/key-events-overview.png)

## Toggle Visibility

You can toggle the display of Key Events using the **Events** checkbox in the filter bar at the top of the Team View. When checked, events will be visible above the calendar; when unchecked, they are hidden.

## Visual Indicators

- **Blue square blocks** — appear on the dates when an event is occurring
- **Calendar date borders** — dates affected by a Key Event will have highlighted borders as a visual reminder

These indicators help engineers quickly identify which dates have special events that may require dedicated attention.

## Event Details

Click on a blue square block to view the full details of the event. The detail panel includes:

| Field | Description |
|-------|-------------|
| **Event Title** | Name of the key event |
| **Start** | Start date and time of the event |
| **End** | End date and time of the event |
| **Details** | Description of the event content |
| **Related Ticket Number** | Associated work order or ticket ID (e.g., Entra ID) |
| **Related Service** | The service category involved (e.g., VM, DB, NET) |

![Key Event details panel](/key-events-detail.png)
